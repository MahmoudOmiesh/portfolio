# Portfolio

TanStack Start with file routes in `src/routes`, MDX content, shadcn (base-nova on Base UI) and Tailwind v4. Every page is prerendered at build time. Package manager is bun.

## Commands

- `bun run check`: typecheck, oxlint (with the vendored anti-slop rules in `tools/oxlint/anti-slop`), oxfmt and `scripts/check-tailwind-scale.sh`, which rejects arbitrary Tailwind sizes and spacing outside `src/components/ui`. Run it before every commit.
- `bun run build`: builds to `.output/`. Serve the build with `cd .output && NODE_ENV=production bun server/index.mjs`. Without `NODE_ENV=production` every page returns 500.
- `src/routeTree.gen.ts` is generated by the router plugin. Leave it to the build.

## Content

All copy lives in `src/content`.

- `profile.ts`: name, about, links, footer.
- `work.ts`: `jobs` in display order. Each job owns its company, role, location, period, description and stories.
- `projects.ts`: `projects` in display order.

To add a work story:

1. Write `src/content/work/<slug>.mdx`.
2. Import it in `work.ts` and add `{ slug, title, cover, Content }` to the job's `stories`.
3. Put the cover and screenshots in `public/<slug>/`.

A project works the same way with `src/content/projects/<slug>.mdx` and an entry in `projects.ts`. The home page lists it and the slug route renders it.

MDX can use `<Screens>` and `<Flow>` from `src/components/work/prose.tsx`. Screenshots are webp at 2x, filled with made-up demo data. Pass the image's real pixel size as `width` and `height`.

## UI

- Build with shadcn components from `src/components/ui`. Add new ones with `bunx shadcn@latest add <name>`. Those files come from shadcn; keep their unused exports.
- Use Tailwind's named scale (`text-sm`, `mt-16`, `max-w-64`), not arbitrary values like `text-[15px]`.
- Text links use the `link` utility from `src/styles.css`. It is the only link style.
- Write code without comments. Add one only for a why the code cannot show.

## Git

- Conventional Commits (`feat(home): ...`, `fix(ui): ...`, `refactor(content): ...`).
- No `Co-Authored-By` trailer or any agent attribution line.
- Lefthook runs oxlint and oxfmt on staged files at commit.
- `drafts/` holds the owner's notes. Never commit it.
